# bench/results — the only source of citable numbers

Honesty law: a number may be cited in the README **only** if the raw JSONL run that
produced it is committed here, named `YYYYMMDD-<model>.jsonl`, reproducible with the
exact command in the top-level README. Negative deltas get committed too.

The `mock-oracle` smoke is a harness invariant, not a result — it never lands here.
